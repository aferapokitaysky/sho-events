## О проекте

SHO Events — монорепозиторий из двух частей:

- **`client/`** — одностраничное React-приложение с полным набором страниц
  (Главная, О нас, Услуги, Форматы, Партнёрам, Контакты), мультиязычное
  (RU / EN / SK), с авторской анимацией и дизайном в стилистике
  *Old Money / Quiet Luxury* — бордовый, кремовый, бежевый.
- **`server/`** — лёгкий Express API, который принимает заявки с форм сайта,
  сохраняет их локально и мгновенно пересылает уведомление в Telegram.

Дизайн полностью авторский: кастомные SVG-иконки, собственная система
анимаций на Framer Motion и вручную свёрстанные компоненты форм —
никаких сторонних UI-китов.

## 🚀 Быстрый старт

**Требования:** Node.js 20+, npm.

```bash
git clone https://github.com/aferapokitaysky/sho-events.git
cd sho-events
npm run install:all
```

Создайте файл окружения для сервера на основе примера:

```bash
cp server/.env.example server/.env
```

Заполните `server/.env` своими значениями (см. [Переменные окружения](#-переменные-окружения)),
затем запустите клиент и сервер одной командой:

```bash
npm run dev
```

- Клиент: [http://localhost:5173](http://localhost:5173)
- API: [http://localhost:4000](http://localhost:4000)

## 🔐 Переменные окружения

Все переменные задаются в `server/.env` (шаблон — `server/.env.example`, в репозитории, без секретов).

| Переменная | Обязательна | Описание |
|---|---|---|
| `PORT` | нет (по умолчанию `4000`) | Порт, на котором поднимается API |
| `CLIENT_ORIGIN` | нет | Разрешённый origin для CORS (через запятую, если их несколько) |
| `ADMIN_TOKEN` | нет | Токен для доступа к `GET /api/submissions` |
| `TELEGRAM_BOT_TOKEN` | нет* | Токен Telegram-бота (создаётся через [@BotFather](https://t.me/BotFather)) |
| `TELEGRAM_CHAT_ID` | нет* | ID чата/группы/канала, куда бот шлёт уведомления о новых заявках |
| `TELEGRAM_TOPIC_ID` | нет | ID топика (если используется супергруппа с темами) |

\* Без токена и chat ID уведомления в Telegram просто не отправляются
(сервер логирует это и продолжает работу в штатном режиме) — заявки всё
равно сохраняются в `server/data/submissions.json`.

> **Важно:** файл `server/.env` уже добавлен в `.gitignore` и никогда не должен попадать в репозиторий.

## 📜 Скрипты

Запускаются из корня проекта:

| Команда | Что делает |
|---|---|
| `npm run install:all` | Устанавливает зависимости и в `client/`, и в `server/` |
| `npm run dev` | Параллельно поднимает клиент (Vite) и сервер (tsx watch) |
| `npm run dev:client` | Запускает только клиент |
| `npm run dev:server` | Запускает только сервер |
| `npm run build` | Собирает production-версию клиента и компилирует сервер |

## 🔌 API

Базовый URL по умолчанию: `http://localhost:4000`

| Метод | Путь | Описание |
|---|---|---|
| `GET` | `/api/health` | Проверка работоспособности сервера |
| `POST` | `/api/contact` | Заявка со страницы «Контакты» (обязательные поля: `name`, `contact`, `message`) |
| `POST` | `/api/partners` | Заявка со страницы «Партнёрам» (обязательные поля: `name`, `company`, `contact`) |
| `GET` | `/api/submissions` | Список всех заявок (требует заголовок `x-admin-token`) |

Все `POST`-роуты защищены rate-limit’ом (20 запросов / 15 минут с одного IP)
и очищают/обрезают входящие поля перед сохранением.

При каждой успешной заявке сервер асинхронно отправляет структурированное
HTML-уведомление в Telegram с группировкой полей (контакт, детали мероприятия,
выбранный способ связи, сообщение) — без блокировки ответа клиенту.

## 🌍 Мультиязычность

Тексты сайта живут в `client/src/content/{ru,en,sk}.ts` и реализуют единый
интерфейс `SiteContent` (`client/src/content/types.ts`). Это гарантирует
на уровне TypeScript-компилятора, что ни один текст не будет забыт ни в
одном из трёх языков. Переключение языка — через `useLanguage()` из
`client/src/lib/LanguageContext.tsx`.
